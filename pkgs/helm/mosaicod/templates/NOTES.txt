mosaicod listens on {{ .Release.Name }}.{{ .Release.Namespace }}.svc:6726.

The pods read the database password and the store secret key from the
{{ .Values.existingSecret }} Secret. If it doesn't exist yet:
  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.existingSecret }} \
    --from-literal=db-password=... --from-literal=store-secret-key=...

mosaicod needs a PostgreSQL role and database before its first start, e.g.:
  CREATE ROLE {{ dig "database" "user" "mosaico" $config }} LOGIN PASSWORD '...';
  CREATE DATABASE mosaico OWNER {{ dig "database" "user" "mosaico" $config }};

Every rollout stops all pods before starting new ones, because mosaicod
migrates the database schema on startup.
